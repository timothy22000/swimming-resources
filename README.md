# Swimming Resources Database

A comprehensive, open-source index of swimming resources spanning every level
of the sport - from infant water-safety programs to elite Olympic-level
governance, biomechanics research, gear, and recruiting services.

[![License: CC BY 4.0](https://img.shields.io/badge/License-CC_BY_4.0-lightgrey.svg)](https://creativecommons.org/licenses/by/4.0/)
[![Code License: MIT](https://img.shields.io/badge/Code%20License-MIT-blue.svg)](LICENSE-CODE)
[![Entries](https://img.shields.io/badge/entries-410-brightgreen.svg)](data/swimming_resources.json)
[![Categories](https://img.shields.io/badge/categories-20-blue.svg)](#categories)
[![Version](https://img.shields.io/badge/version-1.0.0-orange.svg)](CHANGELOG.md)

The database is published as both a **human-readable directory** and a
**machine-readable dataset** (JSON, JSONL, CSV, Parquet). It is also released
as a Hugging Face dataset for use in retrieval-augmented generation, knowledge
bases, and recommendation systems.

> **Hugging Face dataset:** [`t22000t/swimming-resources`](https://huggingface.co/datasets/t22000t/swimming-resources)

## Quick start

### Use the dataset

```bash
# Clone the repo
git clone https://github.com/timothy22000/swimming-resources.git
cd swimming-resources

# Read the structured data (any of these)
cat data/swimming_resources.json        # full canonical JSON
cat data/swimming_resources.jsonl       # one entry per line
open data/swimming_resources.csv        # tabular view
python -c "import pandas as pd; print(pd.read_parquet('data/swimming_resources.parquet').head())"
```

### Or load straight from Hugging Face

```python
from datasets import load_dataset
ds = load_dataset("t22000t/swimming-resources")
print(ds["train"][0])
```

### Rebuild the dataset locally

```bash
pip install pandas pyarrow
python scripts/build_dataset.py
```

`data/` are regenerated by `build_dataset.py`. To contribute or correct a
resource, edit the relevant `data_part*.py` file and re-run the build.

## Schema

Each entry follows this shape (defined formally in
[`data/schema.json`](data/schema.json)):

| Field          | Type            | Notes                                                     |
| -------------- | --------------- | --------------------------------------------------------- |
| `id`           | `string`        | Stable slug, format `<prefix>-NNN` (e.g. `gov-001`).      |
| `category`     | `string`        | One of the 20 categories below.                           |
| `subcategory`  | `string`        | Optional finer grouping.                                  |
| `name`         | `string`        | Display name.                                             |
| `type`         | `string`        | What it is (Federation, App, Book, etc.).                 |
| `audience`     | `string`        | Who it serves.                                            |
| `description`  | `string`        | One-sentence summary.                                     |
| `url`          | `string`        | Canonical URL (must start with `http(s)://`).             |
| `pricing`      | `string`        | `free` \| `paid` \| `freemium` \| `mixed` \| `varies`.    |
| `region`       | `string`        | `global`, a continent, or country code/name.              |
| `language`     | `string`        | ISO 639-1 (`en`, `fr`, `de`, `ja`, …).                    |
| `year_founded` | `integer\|null` | Optional founding year.                                   |
| `status`       | `string`        | `active` \| `rebranded` \| `defunct`.                     |
| `notes`        | `string`        | Caveats, rebrand notes, ISBNs, etc.                       |
| `tags`         | `string[]`      | Free-form tags for search.                                |
| `verified`     | `string`        | `YYYY-MM` of last URL verification.                       |

## Notable governance changes & defunct entries

The dataset includes `status: rebranded` and `status: defunct` flags so that
historical references stay traceable. Highlights:

- **FINA → World Aquatics** (rebrand, January 2023)
- **British Swimming → Aquatics GB** (rebrand, 2024)
- **English Institute of Sport → UK Sports Institute** (rebrand, April 2023)
- **CANA → Africa Aquatics**, **AASF → Asia Aquatics**, **OSA → Oceania Aquatics**, **ASUA/UANA → PanAm Aquatics** (continental rebrands)
- **JASF → Japan Aquatics** (rebrand, April 2025)
- **KSF → Korea Aquatics** (rebrand, February 2024)
- **Singapore Swimming Association → Singapore Aquatics** (rebrand, July 2023)
- **Swim Australia → SWIM Coaches & Teachers Australia** (renamed industry body)
- **SwimVortex** (defunct, 2018) - successor State of Swimming flagged
- **Coach's Eye** (defunct, 2020) - replacement OnForm flagged
- **FINIS Smart Goggle hardware** (defunct, December 2025)
- **OnDeck app** (defunct, December 2024) - replaced by SportsEngine Motion
- **Pac-12 swimming** (defunct as power conference, 2025–26 season)

## Use cases

The structured dataset is intended to power:

- **RAG / retrieval pipelines** for swim-coaching assistants and chatbots
- **Recommendation systems** that suggest training resources to swimmers
- **Knowledge graphs** mapping the swimming ecosystem
- **Directory websites** (the canonical JSON drives the listings)
- **Research and meta-analysis** across the sport's organizations and tools

## Contributing

Contributions are very welcome - corrections, additions, dead-link reports, and
new categories. See [`CONTRIBUTING.md`](CONTRIBUTING.md) for the workflow:

1. Fork the repo.
2. Edit the appropriate `scripts/data_partN.py` file.
3. Run `python scripts/build_dataset.py` (must exit 0).
4. Open a pull request.

Every PR runs the validation workflow in
[`.github/workflows/validate.yml`](.github/workflows/validate.yml).

A weekly link-check workflow flags broken URLs as issues. **Please verify any
URL you add and set `verified: "YYYY-MM"` to the current month.**
