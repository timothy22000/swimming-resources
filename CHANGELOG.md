## [1.0.0] - 2026-05-07

### Added

- Initial Swimming Resources Database release with 410 verified entries across
  20 categories.
- Source-of-truth Python modules in `scripts/data_part1.py` through
  `scripts/data_part9.py`.
- Dataset builder that validates entries and emits JSON, JSONL, CSV, and
  Parquet outputs.
- JSON Schema for individual resource records.
- Contributor documentation, project licensing, issue templates, pull request
  template, validation workflow, link-check workflow, Hugging Face dataset
  card, and publishing guide.
